# REMI AuthBridge

🧠 Patrimonial OAuth Demo using Auth0

REMI AuthBridge is a functional demonstration of REMI's identity and authentication flow using Auth0, deployed on Vercel. It supports bilingual traceability and ceremonial documentation.

🔐 Auth0 Integration:
- Login: `/login`
- Callback: `/callback`
- Logout: `/logout`
