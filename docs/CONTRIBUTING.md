# Contribuciones a REMI AuthBridge

Este proyecto sigue un estándar patrimonial de documentación y trazabilidad.

## Reglas básicas
- Usa commits descriptivos y bilingües cuando sea posible.
- No subir `node_modules` ni binarios grandes.
- Documentar cada flujo en `docs/` con narrativa clara.
- Respetar la separación entre README en inglés y README_ES en español.

## Flujo de trabajo
1. Crear rama descriptiva: `git checkout -b feature-nombre`.
2. Hacer cambios y pruebas locales.
3. Commit patrimonial con mensaje claro.
4. Pull request hacia `main`.
